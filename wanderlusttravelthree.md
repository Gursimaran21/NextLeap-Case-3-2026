# Case 3 : Wanderlust Travel

## Solution to Wanderlust Travel Problem Framing, Ideation & Validation + Metrics: Building a Metrics Dashboard for Wanderlust Travel

**3. Leading vs Lagging Metrics:**

This is a particularly strong PM addition.

**Lagging Indicators**

These tell us **what happened.**
- Bookings
- Revenue
- Search-to-Booking CVR
- Average Booking Value
- Cancellation Rate

**Leading Indicators**

These tell us **what may happen next.**
- Search volume
- Search success
- Result CTR
- Product views
- Search refinements
- Zero-result rate
- Booking initiation
- Search latency

If we only watch bookings, we discover the problem **after** it happens.

The leading indicators reveal the problem much earlier.

A useful dashboard should therefore combine outcome metrics with their drivers rather than treating every metric independently.
